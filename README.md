## 📌 Project Overview

MyBudget is a personal finance management application designed to help
users track expenses, manage budgets, monitor savings goals, and understand
their financial activity.

## ✨ Features

- Expense and income tracking
- Budget management
- Savings goals
- Financial insights
- Transaction management
- User profile and settings
